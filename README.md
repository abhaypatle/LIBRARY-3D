# Avani Library

A smart study library management system built with React, Tailwind CSS, Express.js, and a mock PostgreSQL-ready data layer.

## Stack

- Frontend: React + Vite + Tailwind CSS + Lucide icons + Three.js
- Backend: Node.js + Express.js
- Data: SQLite / PostgreSQL-ready mock store (JSON in-memory layer)

## Getting started

1. Install dependencies:
   npm run install:all
2. Start the app in development mode:
   npm run dev
3. Frontend: http://localhost:5173
4. Backend API: http://localhost:5001

## Features

- Digital kiosk landing page with live seat availability
- 70-seat interactive layout with seat booking and plans
- Student dashboard with digital ID and QR access
- Admin dashboard with analytics, attendance, fee tracking, and manual seat control
- Mandatory T&C flow and promotional offer slider

## Notes

The backend uses in-memory mock data and can be connected to PostgreSQL later without changing the API contracts.
